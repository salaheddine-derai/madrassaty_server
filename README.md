# Madrassaty License Server (سيرفر توليد تراخيص مدرستي)

تطبيق مكتبي مبني بلغة بايثون ومكتبة **Flet** لإدارة وتوليد أكواد التفعيل وتجديد الاشتراكات الخاصة بتطبيق **مدرستي**.

---

### 1. ما الذي نحتاجه من المستخدم (مدير المدرسة) لتفعيل حسابه؟
1. **اسم المستخدم (`username`) - أساسي وإلزامي:**
   - هو الاسم الذي اختاره المدير عند تسجيل الحساب في التطبيق (مثلاً: `ecole_najah` أو `admin_elamal`).
   - الكود الرقمي مشفر وموقع رقمياً (HMAC-SHA256) باسم المستخدم هذا حصراً، ولا يمكن استخدامه على أي حساب آخر.
2. **مدة التفعيل المطلوبة - تحددها أنت في السيرفر:**
   - شهر واحد / 3 أشهر / 6 أشهر / سنة كاملة / تفعيل دائم مدى الحياة.
3. **معلومات اختيارية للتوثيق في السيرفر:**
   - اسم المؤسسة أو المدرسة ورقم الهاتف لتتبع المشتركين في قاعدة بيانات السيرفر (`licenses.db`).

---

### 2. طريقة تشغيل البرنامج:
- اضغط نقراً مزدوجاً على الملف: `run_server.bat`
- أو من موجه الأوامر:
  ```bash
  cd C:\pyProjects\madrassaty_server
  C:\pyProjects\.venv\Scripts\python.exe main.py
  ```

---

### 3. الأمان والتشفير:
- يعتمد النظام على توقيع رقمي عالي الأمان **HMAC-SHA256**.
- لا يمكن لأي شخص تزييف كود التفعيل أو تعديل تاريخ انتهائه دون معرفة المفتاح السري (`secretKey`).
- التطبيق يتحقق محلياً بدون الحاجة لاتصال بالإنترنت.
